# Powerplant Desk

Powerplant engineering desk: AD tracking, engineering support tasks and reliability monitoring.

Deployed automatically to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Notes
- The login screen is a client-side gate only. It keeps casual visitors out but is not real security; do not store sensitive data here.
- Data is saved in each user's own browser (localStorage). It is not shared between users or devices.
